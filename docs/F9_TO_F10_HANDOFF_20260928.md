## Deuda aceptada

`IOS_PHYSICAL = DEFERRED_NON_BLOCKING`.

No es PASS. Falta una futura ejecución física iOS completa de offline → persistencia tras relanzamiento → reconexión → sync → no duplicado → scanner.

Esta deuda no modifica contratos de negocio y fue aceptada como no bloqueante para continuar desarrollo el 2026-09-28.

## CI

Al crear `release/f9-rc2`, GitHub Actions creó CI, iOS Virtual Certification e iOS Certification, pero los jobs finalizaron antes del primer step y sin logs de ejecución. Se registra como incidente de infraestructura de GitHub Actions, no como fallo funcional demostrado del candidato.

No usar ese incidente para convertir CI en PASS. Reintentar cuando Actions pueda asignar/ejecutar runners.
